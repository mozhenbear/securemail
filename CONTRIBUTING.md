# Contributing to SecureMail

Thank you for your interest in contributing to SecureMail! 🎉

## How to Contribute
1. **Report Bugs**: Use our [Bug Report Template](.github/ISSUE_TEMPLATE/bug_report.md).
2. **Suggest Features**: Submit ideas via [Feature Request Template](.github/ISSUE_TEMPLATE/feature_request.md).
3. **Translations & i18n**: We welcome translations in additional languages! See `backend/public/js/i18n.js`.
4. **Code Contributions**: Fork the repository, create a descriptive feature branch, and submit a Pull Request.

## Code Conventions
- Frontend: Vanilla TypeScript / Tailwind CSS / Lucide Icons with zero bloated heavy framework dependencies.
- Backend: Node.js 20 LTS + TypeScript with strict type checking.
- Database: Safe parameterized SQL queries with automatic schema migrations.
- Commit Messages: Use standard conventional commit format (e.g. `feat: ...`, `fix: ...`, `docs: ...`).
