# Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability
We take the security of SecureMail very seriously. If you believe you have found a security vulnerability, please do NOT create a public issue.

Please disclose it responsibly by contacting the maintainer directly at:
- **Email**: `security@zodic.dev` or `mozhenbear@zodic.dev`
- **PGP Key**: Available upon request

We will acknowledge receipt of your vulnerability report within 48 hours and provide regular status updates until the fix is published.
